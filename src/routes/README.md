# Maverick Tutor

Maverick Tutor is a multilingual AI tutoring app built with React, Vite, TanStack Router, and Gemini. It helps users learn AI, machine learning, science, and computing topics through natural conversations in English, Hindi, and Telugu.

It is designed to feel like a friendly educational assistant that explains concepts clearly, answers follow-up questions, and keeps chat history in a lightweight local experience.

## Features

- Multilingual AI tutor support for English, Hindi, and Telugu
- Chat-based learning experience for AI, ML, and science topics
- Local thread-based conversation history
- Customizable widget settings and appearance
- Modern UI with Tailwind CSS and shadcn-style components
- Direct Gemini API integration using the OpenAI-compatible endpoint
- Fast frontend setup with Vite and TanStack Start

## Tech Stack

- React 19
- TypeScript
- Vite
- TanStack Router
- TanStack Start
- Tailwind CSS
- AI SDK
- Gemini API
- Local storage for chat persistence
